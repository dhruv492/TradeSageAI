Capabilities & Modules

Built on Disciplined Financial Engineering

Dual-Model Signal Engine

Infers directional momentum over 1 to 5-day horizons comparing a 100-tree Random Forest baseline with a PyTorch shallow LSTM neural network. Features automatic divergence alerts when models conflict.

SHAP Factor Explainability

Zero black boxes. Every inference exposes quantitative SHAP feature attribution (via TreeExplainer & GradientExplainer), detailing how RSI, MACD, Moving Averages, and Sentiment drove the decision.

Honesty Framework Backtesting

Adheres strictly to the Honesty Framework: avoids misleading raw accuracy metrics and instead computes real-world Sharpe ratio, win rate, peak-to-trough max drawdown, and cumulative equity curves.

Multi-Asset Portfolio Tracker

Supports stocks and cryptocurrencies with live spot price integration from Yahoo Finance and Binance. Features dynamic asset autocomplete search, manual addition with pre-filling, position removal, and CSV batch import.

Watchlist & Shift Alerts

Continuously monitors unheld assets, alerting the trader when model trajectories shift. Built-in feedback loop outcome resolution evaluates historical signal correctness over time.

Cloud DB & Background Retraining

Backed by Neon PostgreSQL cloud storage with complete schema management. Features configurable background daemon schedulers and an on-demand admin batch retrain trigger.

Common Questions

Frequently Asked Questions

Why run two distinct machine learning models side-by-side? +
Single-model algorithmic trading engines frequently fall victim to regime blindness. By pairing an ensemble tree baseline (Random Forest) with a sequence-memory deep model (PyTorch LSTM), TradeSage AI provides a cross-architecture sanity check. When both models agree, confidence is higher; when they disagree, the platform alerts you to divergence.
What happens if the two models produce conflicting signals? +
The interface immediately raises an amber Model Divergence Warning banner. This advises the trader to reduce position sizing or wait for clearer momentum confirmation.
How does the live spot price and portfolio management work? +
Positions are stored in Neon PostgreSQL and re-evaluated dynamically against live prices (via Yahoo Finance for equities and Binance for crypto). You can search assets by typing any letter, auto-fill purchase prices, delete positions with one click, or import batches via CSV.
Does TradeSage AI execute automated live trades? +
No. TradeSage AI is strictly an algorithmic decision-support intelligence platform built for academic research and portfolio tracking. It never places unconfirmed orders on your broker account.
